The core belief is that it is cheaper to build recurring mining robots like the ones in the [[Galactic Resource Utilization Space Inc. External Whitepaper]] that extract critical resources from lunar regolith than a recurring subscription launch fee that brings non-renewables from Earth to the Moon. Extracting regolith is essential for lunar endeavors because [[Lunar regolith can be used for oxygen production in deep-space exploration via flowsheet]], [[Lunar regolith is a useful construction material]], and [[Lunar regolith can be used for radiation shielding in interplanetary habitats]].
