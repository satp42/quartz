A distributed system involves a set of independent processes (nodes/computers/etc.) that pass messages to one another and coordinate to accomplish the same objective. Although each node works in separate silos with coordinated processes, it creates an illusion of being a singular process to the end-user.

Examples of such a system include:
- [[Networking principles in Wi-Fi]]
- [[Blockchain]], specifically [[Gossip Protocol]]

All distributed systems have the following principles:
- [[Fault tolerance in distributed systems ensure resilience to faulty nodes]]
- [[Message ordering creates structure to messages sent in distributed systems]]
- [[Concurrency allow for simeltaneous event changes in Distributed Systems]]
- [[Resource sharing is essential for multi-node networks in distributed systems]]
