RSA is a type of [[Cryptography]] that is an [[Asymmetric key cryptography]] algorithm hence it has a higher sense of security. 

The way it works is the following:
- Each user has a public and private key. The public key is widely known, and the private key is a secret. For the keys, [[The keys in RSA are defined primarily by number theory of primes]]
- **Encryption** works by taking a message that A wants to send to B and using B's public key to encrypt the message A wants to send
- **Decryption** works by decrypting the encrypted message of A using B's private key
