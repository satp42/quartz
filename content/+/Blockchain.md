A blockchain is a universal computer that anyone can upload their own programs into and leave the programs knowing that every program will self-execute. This is primarily because although it functions via [[Decentralization]] it is driven by the principle in [[Distributed Systems]] called [[State Machine Replication]]. Every blockchain is fundamentally a state machine. Blockchains are ran by [[Cryptography]] and proper [[Tokenomics]] to guarantee that every program is executed forever. This is also due to [[Blocks store the state of the blockchain which can be shown on public ledger]].
